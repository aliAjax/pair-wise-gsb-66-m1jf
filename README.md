# 铁路轨道几何缺陷整治与复测平台

基于Vue3、Vuetify、Pinia、Vue Router、Apollo Client、GraphQL、Vite和TypeScript的独立前端工程，使用Canvas绘制里程图。业务数据本地持久化。

## 功能

- 区段、里程、轨距、高低、方向和三角坑检测数据。
- Canvas里程分布、超限点定位、缺陷三角标记和缩放。
- 缺陷筛选、批量派工、工区责任和重复缺陷关联。
- 打磨、捣固、更换、垫板调整等整治记录，复测轮次与关闭校验。
- 正式限速与临时限速冲突联查，区段版本递增。
- 夜间整治离线补录：现场整治记录与复测值先写入本地队列，回网后逐条合并。
- 字段级合并：不同字段的现场补充直接保留；同一字段被现场与调度台同时改过时列出两版并标明来源，人工裁决。
- 缺陷更新导致已计算的限速版本失效时，区段回到待复核并提示调度，不再按旧限速显示。
- 同步失败可继续重试，仅重试未确认项；已接收记录按操作号幂等跳过，不重复写。
- 旧台账无版本号时按首次导入补齐为V1，历史整治记录与复测结果保留可查。
- 完整审计和整治报告导出。

端口为`18466`。

```bash
npm install

npm run dev
```
